# OmindOS Manipulation 产品说明

0.2 新增底盘导航、到达停稳门禁和双 RM75＋腰部联动，入口：`python -m community.rm75_navigation`。
详见[导航联动指南](NAVIGATION_v0.2.zh-CN.md)和[0.2 发布说明](RELEASE_v0.2.md)。

适用版本：OmindOS Manipulation 0.2。维护方：OriginMind 源灵智能。

完整操作顺序见[客户使用手册](CUSTOMER_GUIDE.zh-CN.md)。

## 产品定位

OmindOS Manipulation 用于机械臂运动规划、抓取几何验证与移动双臂任务接口开发。
用户可以先在没有机器人的电脑上验证算法和调用方式，再为实际设备接入驱动与标定参数。
客户与教学科研用户使用同一产品；完整工程称开发版，封装运行包称发行版。
客户包见 [0.2 发行版指南](CUSTOMER_RELEASE.zh-CN.md)。

## 包内包含什么

| 组成 | 交付内容 |
|---|---|
| 原始算法与模型 | WRS / UR3e 运动学、抓取、RRT-Connect、碰撞模型、夹爪和双臂模型 |
| 九项示例 | 快速入门、单臂、抓取、避障、固定双臂、移动双臂、综合任务、腰部 pitch＋双 RM75-B（15 自由度）、底盘导航与双 RM75 联动 |
| Python API | 自定义六关节运动规划、长方体抓取候选、示例任务、状态查询与取消 |
| ROS2 通信示例 | 导航 Action、十二/十三关节轨迹 Action、底座状态消息、模拟服务 |
| 验证工具 | 示例检查、API 测试、任务顺序测试、JSON 结果与自动检查工作流 |
| 设备接入资料 | UR3e TCP/IP 版本读取、ROS2 只读观察、Hand-E / 2F-85 分别配置模板 |
| 文档 | 客户手册、产品说明、安装与 API 指南、设备接入手册、验收记录、版本与来源记录 |

开发版提供源码与依赖清单；发行包提供封装程序、模型/配置、SDK 和示例。
发行包不附带已配置的真机控制器。

## 能力与边界

| 能力 | 当前实现 | 使用时需要知道 |
|---|---|---|
| 单臂运动 | UR3e 六关节正逆运动学示例、自定义关节空间规划 | API 的规划对象是裸臂；未建模夹爪、负载和安装支架 |
| 碰撞检查 | 自碰撞、用户传入的轴对齐长方体障碍物、路径加密采样 | 采样步长为最大关节增量 0.025 rad；不是连续碰撞或硬件安全证明 |
| 抓取候选 | Robotiq85 对居中长方体的若干候选及网格碰撞过滤 | 不验证接触力、力闭合、机械臂可达性和接近路径 |
| 双臂示例 | 十二关节模型、碰撞检查与依次搬运 | 自定义 API 暂提供单臂规划；双臂使用示例入口 |
| 腰部俯仰示例 | pitch 腰关节＋两只 RM75-B 七轴臂的十五关节运动学模型、规划及离线采样 | [参数和运行说明](MOBILE_DUAL_PITCH.zh-CN.md)；整机安装和腰部参考碰撞盒未标定，未验证整机稳定性 |
| 双七轴臂目标机 | 已确认使用睿尔曼 RM75 系列：左右各 7 自由度＋pitch 腰，共 15 自由度，底盘带万向轮 | 已接入官方 RM75-B 标准版模型；具体末端版本、整机安装标定和实际驱动尚待核对，万向轮驱动方式待确认 |
| 移动操作 | 栅格绕障、整机运输包络、停车后双 RM75 与腰部联动；可导入 Navigation 实际仿真定位记录 | 纯运动学；无底盘动力学和硬件控制 |
| Navigation 接入 | 已发布 Navigation v0.1 的实际 Topic 采集与整机回放；保留旧模拟 Action 教学桥接 | 无 Nav2 Action，终点 yaw 不受控；未联调机器人控制器 |
| 设备诊断（legacy/reference） | UR3e Dashboard 版本查询、关节数据与控制器只读观察 | 不能作为 RM75 通过依据；尚未提供真实夹爪及机器人自动抓放执行适配 |
| 停止与状态 | 本地计算任务取消、成功或失败结果 | 查询的是计算任务；停止不发送真机急停信号 |

## 用户如何开始

1. 按[安装指南](INSTALL.zh-CN.md)准备参考环境，下载完整源码与模型。
2. 执行 `python -m community.verify`，确认九项示例全部通过。
3. 执行 `python -m community.api_example`，查看自定义规划的 JSON 输出。
4. 按[API 手册](API.zh-CN.md)替换目标关节值、障碍物或物体尺寸。
5. 需要接入 Navigation 时，按[0.2 导航指南](NAVIGATION_v0.2.zh-CN.md)运行发布镜像和记录回放。
6. RM75-B 现场配置与连接按[0.2 客户验收记录](ACCEPTANCE_RECORD_RM75_v0.2.zh-CN.md)单独核对；[UR3e 接入手册](UR3E_COMMISSIONING.zh-CN.md)仅为 legacy/reference。
7. 使用[RM75-B 0.2 验收记录](ACCEPTANCE_RECORD_RM75_v0.2.zh-CN.md)保存分层结果；[旧版模板](ACCEPTANCE_RECORD.zh-CN.md)保留作历史参考。

## 更换机器人或接入真机

软件不假设客户已拥有某一套配件。当前可直接运行包内 UR3e / Robotiq85 和 RM75-B 双臂参考整机模型；
其他设备需要提供关节模型、尺寸、限位、碰撞几何和驱动映射。

实际接入工作至少包括：机器人及夹爪驱动、关节名称映射、底座与工具坐标标定、
负载配置、速度与加速度限制、轨迹时间参数化、设备状态与停止反馈、现场碰撞模型。
应先完成单臂已知位置抓放的实测，再加入感知、双臂与移动底座。

这些是后续集成任务，不是本版本对任意机械臂即装即用的承诺。

## 如何验收本软件包

- 全新参考环境下可以安装，`pip check` 无依赖冲突。
- 九个离线示例全部通过，并生成结果文件。
- 自定义关节规划能返回起终点正确的路径；被障碍物完全阻挡时返回失败。
- API 可以查询、取消计算，等待超时后终止对应工作进程。
- ROS2 通信测试需单独验收，不能以离线示例通过代替。
- 现场真机结果另行记录，本次软件检查不计作真机验收。
